# 🚀 Quick Start

Guía rápida para ponerse en marcha.

## 1. Instalación

```bash
npm install
```

## 2. Configurar Variables de Entorno

```bash
cp .env.example .env.local
```

Configura las credenciales de autenticación según tu infraestructura.

## 3. Ejecutar en Desarrollo

```bash
npm start
```

Abre: `http://localhost:3000`

## 🧪 Pruebas Rápidas

- **Registrarse**: Email + Contraseña (mínimo 8 caracteres, mayúscula, número, símbolo)
- **Confirmar**: Ingresa código del email
- **Iniciar Sesión**: Accede al dashboard

## 📝 Comandos

```bash
npm start       # Desarrollo
npm run build   # Producción
npm test        # Tests
```
